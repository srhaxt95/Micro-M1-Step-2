เครื่องมือเจาะลึก Binary Up Counter (ข้อ 2)

จำลองการนับเลขฐานสอง 0 ถึง 15 เพียง 1 รอบ พร้อมถอดรหัสบิต (Bit Shift & Mask) ทีละขั้นตอน

1. จำลองหลอดไฟตามตำแหน่งบิตจริง

D3 (เขียว) Pin 10 | MSB (ค่า 8) บิต: 0
D2 (เหลือง) Pin 11 | (ค่า 4) บิต: 0
D1 (ส้ม) Pin 12 | (ค่า 2) บิต: 0
D0 (แดง) Pin 13 | LSB (ค่า 1) บิต: 0
ค่าปัจจุบัน: เลข 0 (0000)

2. ตัวแกะการทำงานของฟังก์ชัน (Bitwise Operation Trace)

const int ledPins[4] = {13, 12, 11, 10}; void setup() {   // ตั้ง pinMode OUTPUT ทั้ง 4 ขา   for (int count = 0; count <= 15; count++) {     displayBinary(count);     delay(500);   }   // ดับไฟเมื่อครบ 15 จบ 1 รอบ } void loop() { /* ว่างไว้เพื่อให้หยุด */ } void displayBinary(int num) {   int bitState = (num >> i) & 1;   digitalWrite(ledPins[i], bitState); }

3. สรุปฟังก์ชันและเทคนิคสำคัญของข้อ 2

1. ทำไมโค้ดการนับต้องอยู่ใน setup() แทนที่จะเป็น loop()?

โจทย์ระบุว่า "for one round" (เพียง 1 รอบเท่านั้น) ในระบบ Arduino ฟังก์ชัน setup() จะรันเพียงรอบเดียวเมื่อจ่ายไฟ ส่วน loop() จะวนซ้ำตลอดไป การใส่ลูปนับ 0 ถึง 15 ใน setup() จึงทำให้โปรแกรมนับครบแล้วหยุดนิ่งทันที ไม่มีการวนกลับมาเริ่มนับ 0 ใหม่อีก

2. การถอดรหัสบิตด้วยสูตร (num >> i) & 1 ทำงานอย่างไร?

* >> i คือ Bit Shift Right (เลื่อนบิตที่ต้องการตรวจสอบไปทางขวาสุด)
* & 1 คือ Bitwise AND เพื่อกรองเอาเฉพาะบิตขวาสุดเท่านั้น หากบิตนั้นเป็น 1 ผลลัพธ์จะเป็น 1 (HIGH สั่งไฟติด) หากเป็น 0 จะได้ 0 (LOW สั่งไฟดับ) เป็นวิธีที่เร็วและแม่นยำกว่าการหารเอาเศษมาก

3. น้ำหนักประจำหลัก (Place Value) ของ LED ทั้ง 4 ดวง

* D0 (แดง): บิต 0 น้ำหนักมีค่าเท่ากับ $2^0 = 1$
* D1 (ส้ม): บิต 1 น้ำหนักมีค่าเท่ากับ $2^1 = 2$
* D2 (เหลือง): บิต 2 น้ำหนักมีค่าเท่ากับ $2^2 = 4$
* D3 (เขียว): บิต 3 น้ำหนักมีค่าเท่ากับ $2^3 = 8$
ตัวอย่างเช่น เลข 13 เกิดจาก $8 + 4 + 1$ ดังนั้นบิตฐานสองคือ 1101 (เขียว, เหลือง, และแดง จะติดพร้อมกัน)

4. ตารางแปลงเลขฐานสิบเป็นฐานสอง (0 ถึง 15)

เลขฐานสิบ ฐานสอง (D3 D2 D1 D0) D3 เขียว (8) D2 เหลือง (4) D1 ส้ม (2) D0 แดง (1) ผลรวมค่าบิต
